# Third-Party Vendor Risk Assessment & Management Program

## 🏢 Project Overview
This repository contains a comprehensive **Third-Party Vendor Risk Management Program** designed to evaluate, audit, and mitigate security risks associated with onboarding cloud-hosted SaaS providers. 

This project simulates a real-world cybersecurity evaluation of a mock analytics vendor (**"CloudVibe Analytics"**) migrating data to an **Amazon Web Services (AWS)** environment. It applies core risk management frameworks from **CompTIA Security+** alongside **AWS Cloud Security** best practices to identify infrastructure vulnerabilities, assess corporate impact, and implement contractual safeguards.

## 🎓 Certifications Applied
* **CompTIA Security+** (Risk Identification, Identity Management, Access Control, Data Encryption Standards)
* **AWS Certified Cloud Practitioner / Security** (VPC Architecture, AWS KMS, AWS CloudTrail, Security Groups)

## 📁 Repository Structure
This program is broken down into three core governance deliverables:
1. **[1_Security_Questionnaire.md](./1_Security_Questionnaire.md):** A standardized, technical cloud-security questionnaire sent to the vendor to evaluate their environment.
2. **[2_Risk_Assessment_Report.md](./2_Risk_Assessment_Report.md):** An audit report translating the vendor's architectural flaws into formal organizational risks.
3. **[3_Risk_Register.md](./3_Risk_Register.md):** A tracking log mapping identified cloud vulnerabilities directly to required technical remediations and legally binding contractual clauses.

## 🧠 Core Competencies Demonstrated
* Cloud Security Architecture (VPC Subnets, Network Segmentation)
* Cryptographic Key Management (AWS KMS, Key Rotation, AES-256)
* Identity & Access Management (MFA Enforcement, Least Privilege)
* Third-Party Risk Management (TPRM) & Vendor Governance
* Contractual Data Protection Clauses & Vendor SLAs
